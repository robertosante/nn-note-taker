# Changelog

Notable changes to Note Taker are recorded here. Releases follow [Semantic Versioning](https://semver.org/).

## 0.5.0 (2026-07-16)

### Features

- Capture and consolidate Google Meet captions by visible speaker.
- Save Obsidian-ready Markdown and raw JSONL through a local Ruby host.
- Choose the meeting directory from the extension or CLI.
- Import browser backups and rebuild notes without duplicating events.
- Move, minimize, and rename the system-native capture panel.
- Run Ruby and JavaScript coverage from the same Minitest task.
